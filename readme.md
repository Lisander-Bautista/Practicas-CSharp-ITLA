# Practicas C# - ITLA

## Descripción

Este repositorio contiene una serie de prácticas desarrolladas en C# como parte del proyecto final. Cada práctica aborda diferentes conceptos fundamentales y avanzados del lenguaje.

---

## Contenido del repositorio (Por ahora)

* 🔹 API REST con ASP.NET Core y Entity Framework (Practica #5)
* 🔹 Otras prácticas futuras relacionadas con C#

---

El repositorio está organizado utilizando ramas para separar cada práctica:

* `main` → Versión estable del proyecto
* `practica-5` → Implementación de API REST

---

## Tecnologías utilizadas

* C#
* ASP.NET Core
* Entity Framework Core
* LINQ
* .NET 6+
